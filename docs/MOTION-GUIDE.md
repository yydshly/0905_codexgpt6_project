# 人物运动与坐下、站起

2026-09-06，分支 `codex/character-guide`。保留现有个人 IP 样版与青年基础版，改进动作控制并增加可保存、可导出的座椅动作。没有重新制作人体外观，也没有接入付费服务。

## 使用

```sh
npm ci
npm run dev
# http://127.0.0.1:5173/?workspace=guide
```

Node.js 22.12+，支持 WebGL 2 的桌面浏览器。开发热更新使用 Vite；已提交模型和动作文件，运行不需要 Python 或 Blender。

新建示例包含 28 秒的三个段落：阅读手册 8 秒、介绍屏幕 8 秒、坐下阅读并站起 12 秒。

已有导览保留原段落：刷新后，在左侧段落列表下点击 **「＋ 添加坐下 / 站起段落」**。选中该段落，在「角色与段落设置」中选择椅子，设置 10–16 秒的总时长。「看坐下 / 看坐姿 / 看站起」可直接定位到对应姿势，点击播放可观看连续过程。支持移除、交换顺序、撤销重做、保存刷新、JSON 和网站包。

坐下段落包含：转向 → 走到椅子前 → 转身站稳 → 屈膝坐下 → 打开手册阅读 → 收起手册 → 前倾站起 → 站稳。时长增加主要用于坐姿停留，进出动作保持固定节奏。人物不会自动移动家具；椅子或通道需要调整时，在房间编辑器布置后重新导入房间 JSON。

## 相对上一版的变化

- 行走相位按实际路程计算，使用约 1.06 米的完整迈步周期；起步、匀速、减速分别计算，替换整段位置缓入缓出与动画权重叠加的做法。正常行走约 0.78 米/秒。
- 出发与到达分开转身，配合交替抬脚；在通道允许的拐角使用圆滑路径。窄通道仍保留保守路径。
- 接入真实的 `Sitting_Enter`、`Sitting_Idle_Loop` 和 `Sitting_Exit` 骨骼动画。以椅子的实际位置、朝向及坐垫高度对齐，修正髋部高度，并用双腿 IK 保持脚部接触。
- 手册跟随身体重心变化；坐稳后打开，起身前收起，避免前倾站起时仍埋头读书。持书行走增加轻微随步摆动。
- 坐姿使用侧面构图，可以看到膝盖、座椅与起身动作。自由观察镜头继续与视频镜头分开。
- 通道被挡住、路程超过当前时长或动作资源加载失败时明确提示，禁用播放 / 视频导出，仍可保留 JSON。不会以悬空坐姿或瞬移完成流程。

## 数据与复用

外层仍为 `ideal-study-guide / version: 1`，角色设置升级为 **`guide.version: 4`**。新动作是 `{ "action": "sit", "itemId": "chair-1", "duration": 12 }`，最多三个段落，每种动作一个。v1/v2 保留旧角色；v3 保留已选角色。迁移均保留旧段落，不自动添加坐姿或覆盖原存档。旧房间 / 短片导入可生成新的导览快照。

`compileGuide` 从当前工程的家具计算路线和座椅位置；`sampleGuide` 按 30 fps 的绝对时间计算位置、方向、动作时间、权重及镜头；`createGuideCharacter.apply` 每次从基础骨骼姿态重新求值。预览、时间轴、视频编码和独立网站共用这条路径，不依赖之前播放到哪一帧。

独立网站包包含所选的角色 GLB，以及 `assets/guide-motion-v1.glb`。可按已有流程解压部署到 GitHub Pages 的子路径。单独使用旧的人物 GLB 仍只有其内置的待机 / 行走片段；要复用本次坐姿、座椅对齐、手册与点击行为，需要同时使用动作文件及导览运行时，或直接使用网站包。普通房间 GLB 和短片编辑器的范围未增加人物。

## 来源

骨骼动作来自 **Quaternius Universal Animation Library [Standard]，CC0**：

- [官方动作库](https://quaternius.itch.io/universal-animation-library)
- 原许可：`src/assets/guide/QUATERNIUS-ANIMATION-LICENSE.txt`
- 本次提取：`src/assets/guide/guide-motion-v1.glb`，598,368 字节；保留原始骨骼通道，不携带示例人体、材质或贴图。
- 提取脚本：`scripts/build-guide-motion.py`。使用本地已下载的 Standard 包执行 `python scripts/build-guide-motion.py <解压目录>`，无需 Blender。

动作资产内包含 Walk_Loop 与三个 Sitting 片段；运行时行走沿用角色 GLB 内的同源 Walk_Loop。原始动画创作属于 Quaternius，不能归为本项目原创动作或本项目录制的真人动捕。项目新增的是路线、节奏、转身、动作混合、座椅对齐、IK、道具衔接与产品集成。外观来源延续 [个人 IP 接入记录](character-ip/INTEGRATION.md)。完整许可同步进入网站包。

## 实际验收与限制

运行证据、测试结果及环境数据见 [本轮验收记录](motion-guide-evidence/README.md)。

这仍是风格化成年角色的骨骼动画，尚未达到写实数字人或为本人定制的表演动作质量。极近景下的手指、书页和衣袖接触仍是简化控制；没有衣物动力学、精细表情表演、任意姿势连续动作规划或完整人体碰撞。转弯、动作起止仍可能看到轻微脚底滑动。

坐姿第一版只支持现有弧背工作椅，遵循其固定尺寸和座面；不支持沙发、床或任意导入椅子的自动适配。地毯按平面高度近似处理，不支持台阶、不平地面或跨地毯边缘的逐足地形适配。

视频为 1280×720、30 fps、无音轨。实际检测并列出当前浏览器支持的编码；本轮验收为桌面 Chrome 的 H.264/MP4。Safari、Firefox、移动端编码未验证，不保证具有相同编码能力。新分支未自动合并或部署到线上主站。
