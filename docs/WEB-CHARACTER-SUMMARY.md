## 新增角色网页怎样关联原工程

工程库顶部提供「角色导览 · 试验」入口。要带入正在展示的房间和作品，在「作品展示」顶部点击同名入口，会生成该房间与作品配置的独立导览快照。

房间、镜头和作品设置属于原工程；导览基于进入时的快照继续编辑，保存到自己的本地键。导览保存不会自动覆盖原工程，原工程后续修改也不会实时同步到已保存导览。更新导览房间可重新导入 JSON 或从作品展示重新进入。

带 `snapshot=...` 的地址依赖原浏览器中的数据，不能当成公开分享链接。其他设备打不开该本地快照时会显示提示和示例；分享给访客应使用实际导出并部署的网站包。本机、线上、不同浏览器的本地存档彼此独立。

## 角色导览网页已补齐的内容

- 左侧角色选择与段落列表，中间真实 3D 预览，设置面板和底部时间轴；提供角色近景、恢复镜头及三种光照氛围。
- 四种已接入的角色：鸣人、青年基础版、以 18 岁成年形象为基准的个人 IP 设定 01／02。个人 IP 仍为样版，未使用本人照片，不承诺肖似本人；鸣人是外部已有角色，不属于自有个人形象 IP。
- 新建示例默认 28 秒：阅读 8 秒、介绍 8 秒、坐下阅读并站起 12 秒。最多三个段落。
- 已有导览保留原段落；可通过「＋ 添加坐下 / 站起段落」加入座椅动作，选择椅子、修改时长、查看坐下 / 坐姿 / 站起、移除和交换顺序。
- 自然行走按路程规划左右落脚点，约束支撑脚、降低抬脚高度，并根据腿长调整重心。骨架坐标中的腿部求解修正了导入模型缩放引起的抖动；起停速度和地毯高度平滑过渡，转身依次抬脚。
- 鸣人另支持双臂后展的忍者跑和介绍前招手；坐姿对齐实际椅子，调整髋部高度和脚部接触，起身前收起手册。
- 预览按显示帧的连续时间更新，视频按 30 fps 使用同一个采样器。保存保留精确的暂停时间，刷新恢复不再取整到相邻视频帧。
- 播放、暂停、拖动、撤销重做、本地保存刷新、JSON 导入导出、真实视频及独立导览网站包。
- 工程外层 v1，角色设置 v5，包含移动方式；读取 v1–v4 时保留旧形象并补充自然行走。导入错误保留当前工程；动作加载、通道阻挡或时长不够时明确提示，禁用无法完成的播放 / 视频生成。

鸣人模型、UV、服装、贴图和描边来自 ronildo.facanha，按作者公开页面的 CC BY 4.0 标注；基础骨架和动作来自 Quaternius CC0。本项目完成权重适配、落脚与姿态计算、书本、椅子对齐及网页集成。模型许可与角色本身的权利分别说明，详见 [角色来源与边界](NARUTO-CHARACTER.md)。前期实现保留在 [个人 IP 接入](character-ip/INTEGRATION.md) 和 [人物动作升级](MOTION-GUIDE.md)。

## 怎样带到其他网页或产品

| 成果 | 可以做什么 | 必须了解的边界 |
| --- | --- | --- |
| 独立作品网站 ZIP | 发布房间、作品介绍和可点击入口 | 解压部署后才有公开网页；更新需重新导出部署 |
| 独立导览网站 ZIP | 发布带人物、动作和作品入口的导览页 | 附带所选角色与动作资源，共用导览运行时；访客页不提供作者编辑和保存功能 |
| 房间 GLB + 对应 JSON + 适配代码 | 在其他网页渲染房间并接入作品点击 | GLB 本身不自动执行网页业务逻辑；不同渲染环境的效果可能不同 |
| 人物 GLB + 动作资源 + 导览运行时 | 二次开发角色展示及导览 | 单独人物 GLB 不包含完整导航、步行落脚约束、坐姿对齐、手册和网页点击逻辑 |
| PNG / MP4 / WebM | 在网站中作为图片或视频展示 | 不包含可编辑 3D 或物件点击行为 |
| 工程 JSON | 备份、迁移、继续编辑 | 不等于托管网站，也不包含整个本地工程历史库 |

代码、角色 GLB、动作 GLB、构建脚本和验收文件均提交在开发分支中。`public/site-kit` 是由构建脚本生成的发布模板，不作为手工维护的源文件入库。日常运行无需 Blender、模型服务或 API Key。

## 人物质量的下一步

当前仍是低模资产与基础动作的网页适配。鸣人脸部为固定表情贴图，没有新增面部表演、口型、布料或头发模拟；服装权重、手指动作和大角度转身仍受原资产限制。Safari、Firefox、真实移动设备和其他编码格式未在最新一轮重新验证。

正式个人 IP 仍需要专属模型、合适的蒙皮和表演动作。制作建议见 [人物质量升级路线](CHARACTER-QUALITY-ROADMAP.md)，其中建议应与已完成的资产接入、步行和坐起修正区分，不作为已交付的电影级效果宣传。
