| 项目 | 实际环境 |
|---|---|
| 操作系统 | Windows 11 家庭版中文版，10.0.26200 |
| CPU / 内存 | Intel Core i9-13980HX / 约 16 GB |
| 实际 WebGL 渲染 GPU | Intel UHD Graphics，ANGLE / D3D11；驱动 32.0.101.6790 |
| 其他安装 GPU | RTX 4070 Laptop GPU；本次 WebGL 没有使用它，不能将结果归于独显 |
| 浏览器 | Google Chrome 152.0.7977.82；自动化运行 headless，启用实际 WebGL |
| 工具 | Node.js 22.15.0、npm 10.9.2、TypeScript 5.9.2、Vite 7.3.6、Three.js 0.180.0、Playwright 1.62.1 |
| 视口与像素比 | 主视觉 1440×900、回归/性能 1280×800，devicePixelRatio = 1 |
| 渲染 | 2048² 方向阴影、SSAO、SMAA；按变化渲染，空闲不持续绘制 WebGL 帧 |

机器原始数据：[performance.json](evidence/performance.json)。测量生产构建、无网络节流，本地导航到 ready 约 **1,011 ms**（包含场景和缩略图创建）。这不是公网冷启动指标。

在 1280×800 窗口、814×603 实际 WebGL 画布内，使用真实鼠标观察拖动，并采集 requestAnimationFrame 间隔。每种氛围取 100 个样本、丢弃前 5 个。默认 8 物件场景包含 171 个 Mesh（其中 15 个实例批次）、约 94,942 个几何三角形（按实例数量计算）；镜头观察时完整多通道渲染约 349 次 draw call。初轮为 1,505 次，相同默认场景下降 76.81%；物件或光照方向变化时仍重新计算阴影。原始 CPU 提交耗时也保存在 JSON，含首次着色器编译开销。

| 氛围 | 有效样本 | 平均帧间隔 | P95 帧间隔 |
|---|---:|---:|---:|
| 白昼 | 95 | 4.43 ms | 8.40 ms |
| 深夜 | 95 | 4.30 ms | 4.30 ms |

这些是短时间本地 headless 样本，不是完整 GPU 时间或所有设备的帧率保证。页面的按需绘制意味着静止时没有有意义的持续渲染 FPS；实测 1 秒静止区间 **0 次新增渲染**。本轮未出现阻断操作的可见卡顿。

## 已知边界与未验证项

- 手动摆放允许家具相互交叠；不做家具间完整碰撞或物理。默认构图与自动添加位置已检查。
- 灯具是实时局部光，第一版没有启用每盏 PointLight 的独立动态投影；方向光负责主要阴影，SSAO 负责接触关系。
- 每个浏览器来源一个手动保存槽，最多 40 件物件，80 条会话历史。未做多方案管理、云同步或跨标签页协同。
- 摄像机为正交室内观察镜头，有缩放和观察角度限制；不穿墙自由飞行，不是完整 CAD 镜头。
- 桌面装饰不是独立物件。桌面台灯/显示器必须依附书桌；删除书桌会级联删除这些物件，可撤销。
- 手机端完整属性编辑未实现；本次仅检查窄屏场景与物件库降级操作。
- **未验证** Safari、Firefox、实际触屏输入、40 物件长期压力、浏览器崩溃恢复、系统级下载拒绝等情况。未将这些情况算作通过。
- 部署至公网未执行；可运行源码、静态构建方式和本地 URL 已交付。

本轮既定范围已关闭，无待执行的交付项。后续如果扩展其他浏览器或手机编辑，应先为这些表面新增验收场景。
