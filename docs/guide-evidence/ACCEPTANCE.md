## 真实导出的视频

- 文件：[xiaohe-guide.mp4](xiaohe-guide.mp4)，7,162,289 字节。
- H.264，1280×720，30 fps，14.5 秒，无音轨；第二段已从默认 8 秒改成 6.5 秒。
- 逐帧生成耗时 13.25 秒。下载后用独立 HTTP 服务重新打开，解码、定位，播放到结尾；没有媒体错误。
- 对比预览与下载文件 1.5s / 5.5s / 10s / 13s 的画面。160×90 采样、RGB 0–255 平均绝对像素差分别为 1.688 / 1.443 / 1.415 / 1.128；阈值 9，允许有损编码误差。演员、机位、房间使用同一个时间采样器。

## 性能实测

在 1440×900 窗口、996×560 预览画布、DPR 1 下，预热后采样 2.001 秒，共渲染 59 帧，实测 29.48 fps（导览主动限制为 30 fps）。composer.render 在 JS 线程上的提交耗时平均 4.91 ms、P95 9.00 ms；这不是隔离 GPU 时间。暂停后 600 ms 内额外渲染 0 帧。单台机器测量，不承诺所有设备达到同样帧率。

复现：先 npm run dev，再 node scripts/measure-guide.mjs。详见 performance.json。
