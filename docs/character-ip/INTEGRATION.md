# 个人 IP · 设定 01 的 3D 接入样版

2026-09-06，独立分支 `codex/character-guide`。基于用户确认的概念方向，将角色接入现有真实书房、导览视频及独立导览网站。此交付是可运行的外观与动作样版；尚不等于概念图中发丝、皮肤和服装精度的最终 IP 定稿。角色名字仍由工程设置，“小禾”是默认占位名。

后续运动升级见 [人物运动与坐下站起](../MOTION-GUIDE.md)：当前角色设置为 v4，新增独立的坐姿动作资产；本文下方 v3 测试数据保留为外观接入时的历史记录。

## 运行与使用

```sh
npm ci
npm run dev
# http://127.0.0.1:5173/?workspace=guide
```

Node.js 22.12+，支持 WebGL 2 的桌面浏览器。日常运行不需要 Blender、外部角色服务或 API Key，GLB 已提交在源码中。

1. 在角色导览左侧上方「角色形象」选择「个人 IP · 设定 01 样版」。新建导览默认使用它；旧导览保留原来的青年基础版。
2. 点击「角色近景」，拖动检查外观；播放或恢复导览镜头可返回原构图。近景属于观察视角，不改变导出视频的镜头。
3. 角色名字、上衣配色、段落时间和顺序沿用原有设置。切换角色也进入撤销/重做历史。
4. 「保存导览」写入当前浏览器；刷新恢复所选角色。JSON 带角色编号，导入后仍可编辑。
5. 「导出视频」使用当前角色、房间与动作；「网站包」只打包所选角色，解压后通过 HTTP(S) 服务器或 GitHub Pages 发布。

原版房间布置、短片和作品管理保持原有范围。角色目前由角色导览工作区使用，普通短片编辑器与房间 GLB 导出没有自动新增人物。

## 数据兼容与一致性

- 导览外层和本地键仍为 `ideal-study-guide / version: 1`。角色设置升级到 `guide.version: 3`。
- 旧设置 v1/v2 解析为 v3，继续使用 `creator-18-v1`，不静默换脸；房间、作品、名字、配色、段落、顺序及播放位置保留。点击保存前不写回旧存档。
- 新导览为 `personal-creator-01-v1`。v3 允许这两个已登记编号，拒绝未知编号与未来版本。
- 加载新角色成功后才提交工程和历史，并释放旧模型。切换失败保留旧工程、旧模型、选择器和历史；加载期间锁定修改，避免一套数据显示另一角色。
- 预览、拖动播放头和视频调用相同的绝对时间采样与角色驱动；网站带相同 `project.json` 和所选 GLB。
- 新旧网站包各自只包含对应模型，普通作品网站包仍不包含角色文件。发布运行时通过相邻路径读取模型，不依赖编辑器、本地存档或外部模型 CDN。

## 二次开发边界

单独 GLB 可在支持 glTF 2.0 的应用中复用外观、骨骼、`Idle_Loop`、`Walk_Loop` 和 morph。阅读、翻页、介绍作品、导航与点击属于导览运行时代码，完整保留这些行为应复用运行时或发布的网站包。手持书也是运行时生成的道具。

后续更换正式 IP 模型，应新增资产编号，适配骨骼、材质和表情约定，并重新检查手册接触、通道宽度、镜头构图及导出。不能仅将任意 GLB 重命名后视为兼容。

## 已知限制

- 外观是程序制作的风格化样版，与概念图仍有明显精细度差距，特别是发束轮廓、皮肤层次、眼睑、衣褶和鞋型；还需要视觉评审与造型精修。
- 延续 18 岁成年青年设定，未使用用户照片，不承诺肖似用户本人。
- 眼镜使用实体镜框，无真实折射镜片；没有口型驱动、语音、布料或头发物理。
- 待机/行走复用基础动画，阅读与介绍用 IK；手指和书页接触为简化控制，极近景仍可能看到小范围接触偏差。
- 视频继续为 1280×720、30 fps、无音轨，实际编码格式由浏览器检测；本机验证不能代表所有设备性能。
- 本分支尚未合并或部署到线上主站。
