# 3D 镜头与短片工作台 · 交付约定

- 入口：在当前理想书房上实施新产品能力，独立分支 `codex/film-workbench`，基线 `790c0ea`。用户已授权实施、测试、生成视频及 GitHub 分支提交；不替换线上 main 站点。
- 路线：产品案例 / 空间配置器上的电影镜头工作台。现有输入为同一套房间、八类物件、材质、灯光和 Three.js 渲染器；输出为可操作工作台、版本化工程及真实视频。项目证据写入本仓库，不扩展技能或外部业务。
- 视觉与架构：Immersive / Spatial Stage。左镜头卡片，中间持续可见的 16:9 实时 3D，右镜头属性，下方时间轴。沿用米白、暖木与森林绿，预览周围用深色画框集中注意力。
- 默认作品：10 秒、3 段，完整全景入场 → 桌边细节 → 留白收束。小幅、有目的的镜头运动，段内平滑启停；不随机绕场。默认自动播放一次，低动态偏好下静止在首帧并提供播放入口。
- 操作：播放/暂停、时间轴拖动与键盘定位、选择镜头、起终机位、观察目标、时长及排序、撤销重做、本地保存恢复、工程 JSON 与视频导出。最多 3 段，每段 1–10 秒，总长最多 30 秒。
- 摄影约束：正交投影复用原镜头与场景；以固定安全半径的水平角/俯角/缩放表达起终机位，观察目标在房内。统一纯时间采样供预览、拖动、逐帧编码；固定输出 1280×720 / 30 fps / 无音轨。
- 兼容与数据：工程 envelope v2 包含原始 scene v1 与 film 数据，独立存储键；旧 v1 导入迁移为默认短片，不修改旧 v1 存档。保留原空间编辑器模块，并能编辑当前短片里的房间。
- 导出：检测实际 WebCodecs 编码支持，优先 H.264 MP4，备用 VP9/VP8 WebM；逐帧时间戳编码并封装，失败/取消无成功提示，结果可在产品中回放及下载。不接摄像头、麦克风，不加字幕、音乐或 AI。
- 环境：桌面 Chrome 为实际主验收，1440×900 与 1280×800；窄屏明确桌面编辑边界并保留预览/播放。无 WebGL / 编码能力时仍提供可读界面和工程备份；无编码时禁用视频导出并说明原因。
- 主流程与停止条件：打开默认作品 → 修改第二个镜头 → 预览 → 保存刷新 → 导出 → 打开文件检查。随后只修验收问题，不增加无关能力。
- 最终交付：源码和启动说明、最多六张当前工作台证据、实际导出视频、ffprobe 时长/尺寸/帧数、浏览器重新播放与画面对应性、完整操作与兼容回归、环境/性能/已知限制、独立 GitHub 分支记录。

## 阶段终审

- 效果阶段：复用场景建立全景、桌边近景和较高收束三段；真实浏览器检查双桌面布局，修正画幅与面板可见性。
- 操作阶段：完成镜头修改、历史、工程保存恢复、原编辑器联动和视频生成/回放。
- 修正阶段：主流程通过后只修正验收问题并完成原版回归、编码兼容与子路径检查。没有扩展账号、云同步、音乐或其它产品功能。
