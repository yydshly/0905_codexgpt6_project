# 通用作品入口与可部署个人展示页

- 修订：用户确认所有物件应支持作品关联，配置后的房间应能形成独立个人展示页并部署。基线 df582ac；增量分支 codex/publishable-portfolio。
- 授权：实现、浏览器验收、提交并推送现有仓库；不需要重复确认普通可逆实现选择。发布能力交付为可下载的独立静态网站包；用户尚未指定要公开的个人内容或新站点，不替换现有线上编辑器。
- 类型：revision-led，Immersive / Hybrid Workspace。持续 3D 场景、前景控制与作品详情；保留现有材质、字体、镜头、布置、短片、历史和本地保存。
- 范围：11 类家具整体绑定；书籍/屏幕部位绑定优先；个人名、标题、简介；发布预览与独立 ZIP；相对路径，可在根路径和 GitHub 仓库子路径运行，访客不依赖作者浏览器存储。
- 数据：portfolio v2，自动读取 v1；房间/短片外层版本保持，嵌套版本独立迁移；GLB 使用 itemId/partId 标识，整体使用 object。
- 主流程：关联相框等物件 → 书桌整体/书籍绑定不同项目 → 保存刷新/撤销/导入导出 → 设置个人展示内容 → 预览 → 下载 ZIP → 在另一静态服务器和新浏览器上下文打开 → 点击物件/作品访问链接。
- 默认 URL：npm run dev，http://127.0.0.1:5173/?workspace=room；生产 npm run build && npm run preview，4173。部署包以独立 4180 测试服务器验证。
- 第一印象：完整可探索房间配个人标题、清晰作品入口；访客页不出现编辑器/导入/开发者按钮。窄屏保留场景和作品列表，详情为底部面板；无 WebGL 时作品列表可访问。
- 交付：源码与启动说明、GitHub 提交、至少 3 张实际截图、实际发布 ZIP、操作/迁移/性能记录。未指定个人站点公开部署不计为已发布。
