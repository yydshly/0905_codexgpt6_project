# 小禾 · 角色导览原型

基于原版理想书房，验证「空间 + 角色行为 + 作品内容 + 可发布网页」的最小产品链路。独立分支 `codex/character-guide`，基线 `40954bc`；原版房间、短片、作品集和工程库继续使用原来的实现与数据版本。

## 体验与操作

```sh
git switch codex/character-guide
npm ci
npm run dev
```

打开 http://127.0.0.1:5173/?workspace=guide 。默认是带真实示例作品关联的书房，两个段落各 8 秒，共 16 秒，点击「播放导览」开始。默认暂停，不擅自打开详情或外部链接。

1. 点击「书页间的灵感」或「屏幕里的创作」选择段落，拖动底部播放头查看同一时间的画面。
2. 左侧「角色与段落设置」可以修改导览名称、角色名字、三种服装颜色、每段 6–12 秒时长（0.5 秒步长）、交换顺序。左侧可滚动。
3. 点击场景里的书籍 / 屏幕标记，从对应段落起点播放，完成后打开已关联作品详情。选择另一入口会取消之前的播放。直接查看作品可以跳过动作。点击外部链接才在新标签打开项目。
4. 拖动画面旋转或滚轮缩放会暂停导览。「恢复导览镜头」回到当前时间对应的机位。手动观察的镜头不写入导览，也不会影响导出。
5. 保存导览后刷新，房间、作品、角色设置、时长、顺序与播放位置恢复，播放保持暂停。保存仅在当前浏览器。
6. 视频导出检测实际编码能力，生成 1280×720、30 fps、无音轨 MP4/H.264 或 WebM/VP9/VP8。生成后先读取视频尺寸、时长，再提供浏览器回放与下载。
7. 「JSON」下载完整导览工程；「网站包」下载包含运行时、房间、公开关联作品与角色数据的独立 ZIP。解压后用静态服务器打开，或按包内说明部署到 GitHub Pages。不依赖作者存档。

导入你自己的内容：在原来的书房中布置并关联作品，然后进入「作品展示」，点击顶部「角色导览 · 试验」，当前预览里的房间和作品配置会作为快照传入。也可以在导览页导入旧房间 / 短片 JSON。默认从已关联作品的书桌和显示器各选择一个，没有已关联项时选择同类第一个物件。

## 数据与复用

新增独立格式 `app: ideal-study-guide, version: 1`，内部包含原版 `FilmProject v4` 快照与 `guide.version: 1`。原版 `Plan v3 / FilmProject v4 / Portfolio v2` 和 IndexedDB 工程库没有升级或迁移写入。导览解析器能读取原有房间 v1–v3、短片 v2–v4，并创建独立导览；新版导览 JSON 应在导览页导入。

导览本地键为 `ideal-study.guide.v1:<来源 ID>`。默认示例使用 `demo`；从作品展示进入的快照使用独立 UUID。快照 URL 只适用于创建它的浏览器；对外分享请导出网站包。原工程更新不会自动更新已经保存的导览快照；重新传入或导入 JSON 即可。

`guide-model.ts`：工程校验、旧格式包装、确定性地面路径、绝对时间采样。

`guide-character.ts`：独立角色几何、关节与道具、阅读 / 介绍动作。自行制作，没有下载人物或动作素材。

`guide-view.ts`：同一套采样用于播放器、时间轴定位与视频帧；访客与作者共用预览。访客没有保存、导入或设置入口。

`film-export.ts`：抽出共享逐帧编码器，原有短片编码继续调用；没有生成另一套「导出专用演示」。

`guide-site-export.ts`：复用原网站打包与公开作品过滤。原网站包继续使用原版作品展示；新格式选择角色导览运行时。

## 这一版的边界

- 原型是两段编排好的作品导览，不是陶陶的完整玩具世界；没有随机自主生活、语音、对话或行为编辑器。
- 阅读动作翻阅的是角色随身手册，没有从桌上拿书、坐下、抓取或精确手指绑定。屏幕动作为抬手介绍，不是触摸屏幕。
- 风格化角色为程序几何和关节动画，不是精细皮肤、布料模拟或动作捕捉。动作尚有简化的脚步与接触细节。
- 时间轴 / 热点段落跳转会直接定位到该段落的起点。完整导览连续播放；不支持从任意中断姿态无缝接续另一动作。
- 路径用 0.15 米网格和 0.26 米角色半径绕开静态家具。没有完整物理；布局太拥挤会拒绝播放并提示。任意复杂布置的机位美观不能自动保证。
- 默认最多一个书籍段落和一个屏幕段落；其他作品入口仍直接显示详情。没有加入更多角色或动作种类。
- 新导览为独立快照，本轮未接入工程库的多版本管理；每个来源保存一份导览，修改历史只在当前打开期间。重要导览请备份 JSON。
- 角色动画暂不包含在原 GLB 导出中。当前可复用形式为导览 JSON + 网页运行时、独立网站 ZIP 或视频。视频与网站中都包含角色。
- 视频导出需要安全上下文及兼容的 WebCodecs 编码器，不提供服务端转码。没有音频；不声明 Safari / Firefox 的视频导出已经实测。
- 本分支没有合并到 main，也没有替换公开 GitHub Pages 主站。
