## 存储与迁移

工程只保存在当前浏览器。发布代码不会上传本机工程；本机与线上地址不共享存档。

将现有工程带到线上：本机「我的工程」→ 卡片「备份 JSON」→ 打开线上「我的工程」→「导入 JSON 为新工程」。每次 JSON 包含一套工程的当前房间、镜头和作品配置，不含整个历史版本库。

旧版线上快速存档保留，首次进入工程库按来源和内容迁入；旧房间/短片格式继续迁移。删除工程不会删除旧快速存档或已经部署出去的独立网站。

## 边界

- 没有账号、云同步、多人协作、整库历史备份或回收站；确认删除不可撤销。
- 原顶部工作区切换仍会先保存；「我的工程」菜单可选择不保存返回。
- 主要支持桌面浏览器，真实手机 GPU、Safari/Firefox 尚未完成验收。
- 视频为无音轨 1280×720、30fps，实际编码格式取决于浏览器支持；需要 HTTPS 或本机安全上下文。
- 独立展示网站需再次导出、部署才能更新；GLB 单文件不会自动包含整个网页交互逻辑，PNG 和视频没有物件点击行为。
- 仍有原 Three.js 大包提示；不将特定测试机的性能作为所有设备保证。

启动与完整命令见 [README](../README.md)，各阶段实际截图、视频、模型及操作记录也从该文档索引。
