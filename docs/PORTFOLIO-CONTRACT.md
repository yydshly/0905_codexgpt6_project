# 物件关联作品 · 本轮交付约定

- 授权：用户要求先提交当前项目，再继续实现前一轮分析的作品交互。基线 428cd19 已在 origin/codex/reusable-study；在 codex/portfolio-interactions 开发，不部署或替换 main。
- 类型：增量产品扩展；Immersive / Hybrid Workspace。复用现有场景、暖木配色、字体、光照、镜头、编辑历史和本地保存。
- 用户：作者在房间编辑器配置作品；访客在持续可见的 3D 房间中探索。普通网页承担可读内容和项目访问链接。
- 范围：每张书桌的一本现有书、每台显示器的屏幕；项目标题/简介/技术栈/封面/HTTP(S) 链接；作品绑定、详情、取消绑定、作品列表、JSON 与 GLB 携带标识、播放器与 iframe 通知宿主。
- 不扩展：任意网页嵌入屏幕、动态视频纹理、任意部位建模、账号、云保存、收费服务。默认示例使用本项目的真实仓库和已有公开页面，明确标记示例。
- 数据：房间 v3，短片 v4，portfolio v1；旧方案升级为空作品配置，原存储保留。删除家具时同时清理绑定，撤销完整恢复。图片随工程保存。
- 操作：布置中配置；展示中点击打开详情，拖动仅观察；播放短片时停用热点，暂停后恢复；遮挡物后不能点击。详情支持 Escape、焦点返回、键盘作品列表。
- 界面：保留既有编辑器；新展示入口直接可见；展示页使用全屏场景、简洁标题和底部作品条。窄屏作品列表横向滚动、详情为底部可滚动面板；无 WebGL 时作品列表仍可用。
- 主流程：书桌绑定作品 → 屏幕绑定项目 → 预览 → 真正点击模型 → 移动/旋转/材质 → 撤销重做 → 保存刷新 → JSON 导出导入 → 独立宿主读取并接收点击 → GLB 导出重新加载检查标识。
- 运行：npm run dev，http://127.0.0.1:5173/；验收用 npm run build && npm run preview，http://127.0.0.1:4173/。桌面 1440×900、1280×800，展示页补充 390×844。
- 必交付：源码、GitHub 分支提交、3–5 张真实截图、可导入工程与 GLB、操作记录、性能和已知边界。
