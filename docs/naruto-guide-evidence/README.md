# 鸣人角色：真实运行验收（2026-09-06）

独立分支 `codex/anime-character`，基于角色 02 已交付版本。这里的 PNG 均为真实 Three.js 浏览器运行截图，MP4 和 ZIP 均通过产品按钮下载；不是设计图或预渲染替身。

## 验收结果

15 项浏览器用例通过（`browser-tests.json`）。最终补充网站包署名及忍者跑设置后，相关 2 项用例再次通过（`website-motion-recheck.json`）。测试使用与 GitHub Pages 一致的 `/0905_codexgpt6_project/` 子路径；远端线上部署未在本轮执行。

已实际完成：打开默认鸣人 → 选择忍者跑 → 修改第二段时长与配色 → 播放、暂停、拖动 → 撤销重做 → 保存 → 刷新恢复 → 导出 JSON 并重新导入 → 导出视频 → 下载后在独立页面打开，播放至结束。保存和 JSON 往返关键数据完全一致，无效数据与缺失模型不会覆盖工程，也不会显示导出成功。

另外实测了自然行走和跑步的姿态差异、介绍前招手、同帧重复采样、坐下／坐姿阅读／站起、移动与旋转椅子后的位置对齐、受阻路线提示、旧 v1–v4 导览迁移、角色 01／02 切换及旧资源保留、独立网站子路径加载、作品链接、移动方式与许可信息打包。新角色不提供面部骨骼，因此没有用旧角色的眨眼测试冒充新角色能力；旧角色 02 的眨眼仍单独验证。

## 测量环境

Windows，Chrome **152.0.7977.82**，Intel UHD Graphics，ANGLE / Direct3D 11，WebGL，设备像素比 1。浏览器自动验收使用独立存储的无头 Chrome；同时在用户打开的应用内浏览器查看了新角色。Node.js 22.15.0，Three.js 0.180.0，Blender 4.5.3。

1440×900 窗口、996×560 场景画布：2.005 秒观测到 60 次场景渲染，**29.93 fps**；导览本身限制为 30 fps。JS 提交渲染平均 2.28 ms、P95 2.70 ms，非独立 GPU 耗时。576 次 draw calls，场景 105,188 三角面；暂停后 600 ms 内无重复渲染。冷浏览器本地加载到可用为 1.911 秒，不能等同于公网下载速度。原始记录见 `performance.json`。

模型 GLB 2,429,904 字节，67 骨骼、6 个蒙皮网格、5 张嵌入图片。资源哈希及包含的动画列在 `assets.json`，作者公开元数据和源压缩包哈希列在 `source.json`。

## 限制与未验证项

这版是低模动漫角色接入，面部为 128×128 固定笑脸贴图，未实现眨眼、口型或面部表演，也不包含忍术、战斗、配音、布料模拟。大幅关节弯曲仍会显示低模折角，不能当作电影级动画资产。阅读、招手和忍者跑上半身属于运行适配，不是火影动画制作方的原始动作。

Safari、Firefox、真实手机设备性能、不同显卡及远端公网部署本轮未验证。编码器采用浏览器实际能力检测，本机验证了 H.264；无编码器和无 WebGL 的错误界面已测，不能据此保证其他浏览器也支持视频导出。完整资源来源、v5 迁移规则与复用方式见 [接入说明](../NARUTO-CHARACTER.md)。

复测命令：`npx playwright test --config playwright.pages.config.ts tests/guide.spec.ts tests/guide-motion.spec.ts tests/naruto.spec.ts tests/publish.spec.ts`。证据目录通过 `GUIDE_EVIDENCE_DIR` 指定；性能脚本 `scripts/measure-guide.mjs` 应在其他测试停止后单独执行。
