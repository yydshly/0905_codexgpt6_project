2026-09-06。根据当前人物观感反馈整理。本文是后续制作建议，不代表已制作新的正式角色或已达到写实数字人质量；网页已完成的能力见 [阶段归纳](WEB-CHARACTER-SUMMARY.md)。

进度更新：已制作[个人 IP 02](character-ip/EDITION-02.md)的头脸、发型和领口，并交付 Blender 源文件、GLB 与真实运行证据。下文的定制表演、精细贴图、修正形变和最终 IP 美术验收仍是后续建议。

## 当前判断

已有版本完成角色接入、动作播放、座椅适配、保存与发布。但人物资产和动画表演仍达不到期望。继续调整速度、角度、骨骼位置可以改善局部，不能替代正式角色造型、绑定和动画制作。

| 层次 | 影响 | 后续工作 |
| --- | --- | --- |
| 模型与材质 | 静止时的品质和 IP 辨识度 | 精修脸型、眼睛、发束、手部、衣服轮廓和材质层次 |
| 骨骼与蒙皮 | 弯腰、屈膝和转身时的变形 | 检查肩膀、髋部、手腕、膝盖与衣袖，必要时制作修正形变 |
| 动画素材 | 重心、步幅、节奏和角色气质 | 使用授权清楚的动画或动捕素材，并针对本角色调整；通用素材不直接等同于定制表演 |
| 动作控制 | 动作衔接及与物品的关系 | 协调停步、转身、脚底固定、持书、坐下和站起；代码根据房间做局部适配 |
| 渲染 | 人物质感和空间融合 | 统一皮肤、头发、衣物、阴影及房间光照，并检查网页性能 |

骨骼数量、面数或增加动作按钮，不能单独作为人物质量标准。Three.js 已支持骨骼、形变与动画混合，现有框架可以继续作为接入基础。[Three.js 动画系统](https://threejs.org/manual/en/animation-system.html)、[Blender 动画与绑定](https://www.blender.org/features/animation/)。

## 建议制作顺序

1. **正式角色资产。** 沿用 18 岁成年设定，精修模型、贴图和绑定。先验收正面、侧面、背面及脸部近景；交付可编辑源文件、纹理、骨架和网页可用 GLB。若需要肖似本人，应先确定本人参考与认可的设计，当前原创样版不能作为肖似承诺。
2. **统一基础动作。** 先做待机、起步、行走、停步、转身、坐下、坐姿和站起。对动作迁移后的步幅、肩髋关系、手势与地面接触逐项精修。
3. **动作衔接和物品适配。** 基础动画负责身体表演，程序根据椅子和书本位置调整脚、髋部与手。保留收书、前倾、站起等行为顺序，避免只移动整体高度来模拟坐姿。
4. **接回原产品。** 继续复用房间、时间轴、作品关联、保存、视频和网站发布。新增正式角色编号，适配骨骼、材质和表情接口，不能靠重命名任意 GLB 假定兼容。

综合网页实时运行、个人辨识度和长期复用，建议先采用精致风格化的成年角色，并追求可信的身体运动。这是建议方向，尚未确定最终美术方案，也没有采购、外包或新增费用。

## 下一阶段验收样片

先独立检查一个角色的三组内容，再接入完整房间：

- **静态与近景**：脸部、头发、眼镜、手部、服装轮廓在多个方向均达到认可的设定，不能依靠远景遮掩造型问题。
- **走、停、转身**：检查重心和步幅、落脚、身体协调及动作衔接；循环和暂停恢复不出现明显跳变。
- **坐下与站起**：身体和椅子有可信接触，脚不明显滑动，衣袖、手指及书本没有显著穿插。

接回房间后再检查两种桌面尺寸、房间光照、修改椅子位置、保存刷新、同帧预览与视频以及独立网站播放。测试通过与美术观感验收分别记录；未达标时继续修正人物，不以新增无关功能代替。

## 继续保留的边界

这份路线不包含账号、云同步、语音或大模型接入。沙发、床、任意外部人体和座椅的自动适配、完整人体碰撞与衣物动力学，也不计为当前已实现能力。外部素材需保留来源与适用许可；原始模型与动画质量不归为本项目自行制作。
