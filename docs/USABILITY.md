# 第三轮优化 · 物件管理与导入保护

2026-09-05。实现提交 [`bed88e8`](https://github.com/yydshly/0905_codexgpt6_project/commit/bed88e8)，弹窗反馈修正 [`498fc1b`](https://github.com/yydshly/0905_codexgpt6_project/commit/498fc1b)。

## 这轮解决的问题

真实浏览器检查发现：两盏台灯显示同名；选中物件后，右侧缺少直接切换物件的入口；JSON 中指向房间外的镜头会被接受，导致空画面。修正后又检查到导入错误提示位于原生模态弹窗之外，会被遮罩模糊，已一并修正。

- **直接切换物件**：右侧顶部选择器在空间概览和编辑状态中始终可用。支持原生键盘操作，方向键操作选择器时不会误移动家具。
- **物件命名**：重复物件自动编号；点击名称旁的铅笔区域即可输入名称。名称在选择器、场景标签和物件列表中同步，支持撤销重做、本地恢复和 JSON。空名称、超过 24 字符的名称及 UI 中的重名有明确反馈。
- **安全导入**：先验证镜头目标、观察角度、缩放和距离，拦截房外、退化或超出支持范围的镜头。名称字段也先校验。失败不改变方案、历史或已保存数据。
- **可读的文件反馈**：导出或导入时，进度、成功和失败提示直接显示在弹窗内部；关闭弹窗后恢复普通通知位置。

场景几何、材质与渲染品质沿用第二轮。本轮没有增加外部依赖或素材。

| 表面 / 操作 | 实际结果 |

## 边界

仍为单房间、单个本地保存槽，无家具间完整碰撞。手机完整属性编辑、Safari/Firefox、40 物件长期压力仍未验证。导入手工修改的镜头时，必须满足本应用的观察范围；不支持通过 JSON 导入自由飞行镜头。完整边界见 [验收报告](VERIFICATION.md)。
