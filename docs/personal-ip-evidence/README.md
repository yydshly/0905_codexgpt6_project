# 个人 IP 样版 · 实际运行验证

以下是运行页面、下载文件和浏览器测量，概念图另见 `docs/character-ip/concept-01.png`。测试使用隔离浏览器环境，没有清除或覆盖用户的工程存档。

## 文件说明

- `01`–`03`：默认导览、阅读与屏幕介绍，1440×900 / 1280×800。
- `04`–`05`：实际导出视频在应用内回放、下载后独立打开。
- `06`：解压网站包后，在隔离存储与独立 HTTP 子路径中运行。
- `07`–`12`：近景、俯视、另一角度、正面与侧面。文件名中的 adult 表示沿用已有验收脚本，截图内实际模型编号见 JSON。
- `13`–`15`：个人角色近景以及白昼、黄昏、深夜；小窗口的深夜按钮通过正常点击操作。
- `xiaohe-guide.mp4`：浏览器实际编码、下载并重新播放的视频。
- `xiaohe-guide.website.zip`：个人 IP 网站包；`legacy-avatar.website.zip`：兼容旧角色的网站包。均为测试作品数据。
- `verified-guide.json`：验收中的导览数据，可重新导入继续编辑。
- `journey.json`：保存刷新、JSON 往返、实际编码、回放及四帧图像比对。
- `avatar-frame-check.json`：独立计算人物上半身/头部区域，对比下载视频与预览；另用旧角色做反例，确认比对能发现不同人物。
- `adult-avatar.json`：实际加载的模型编号、骨骼、蒙皮网格、表情和确定性采样。
- `performance.json`：本机环境、帧率、JS 提交渲染时间与暂停后渲染次数。

## 验证方法

```sh
# 在 GitHub Pages 仓库子路径构建下执行实际 Chrome 操作
# PowerShell 环境变量写法：$env:GUIDE_EVIDENCE_DIR='docs/personal-ip-evidence'
npx playwright test --config playwright.pages.config.ts tests/guide.spec.ts tests/publish.spec.ts

# npm run dev 启动后，独立测量与人物区域比对
node scripts/measure-guide.mjs
node scripts/verify-guide-avatar-export.mjs
```

测量脚本同样需设置 `GUIDE_EVIDENCE_DIR`，避免写入旧版证据目录。运行时无需 Blender；仅重制角色资产时使用 Blender 4.5.3。

## 检查与修正记录

1. 通过实际近景修正头脸曲面的分段起伏、颈部断口、眼睛浮出以及开襟三角形锯齿。
2. 通过实际侧面检查发现内搭穿出外衣，收紧内搭并统一躯干权重；手册改为随 IK 后的实际手掌位置携带。
3. 1280×800 中原绝对定位的光照按钮被说明区域挡住，调整到正常布局，并在验收中加入正常点击深夜/白昼的检查。
4. 新增旧角色网站用例首次失败，原因是测试服务器把 HTML 以二进制下载类型返回；修正 MIME 后重新独立打开成功。
5. 额外人物区域检查最初使用了不支持 Range 的临时视频服务器，跳转回到 0 秒；改为正确的字节范围响应，并校验实际播放时间后重新比对。正式导出验收原本就使用 Range 服务器。

浏览器测试不等于造型审美定稿。发束、皮肤与衣服细节仍是样版水平，极近景手指接触可能存在细小偏差。Safari、Firefox、真实手机及慢网络没有在本轮完整验证。完整资产来源与二次开发边界见 [接入说明](../character-ip/INTEGRATION.md)。


## 本次最终结果

- 实际浏览器验收 **12/12 通过**：角色导览 8 项、共用发布 4 项，全部来自最终模型与代码的 Pages 子路径构建；见 acceptance.json。原版其余工作区没有在本轮本机全量重跑，历史结果不计入这 12 项。
- 环境：Windows 11，Chrome 152.0.7977.82，Intel UHD / ANGLE D3D11，桌面窗口 1440×900 与 1280×800，DPR 1。
- 视频：H.264 MP4，14.5 秒，1280×720，30 fps，无音轨，7,526,879 bytes；本次编码约 13.29 秒。已下载、重新打开、跳转四个时间点并实际播放到结束。
- 整体画面四帧 MAE：1.58, 1.43, 1.38, 1.30；有损视频不要求逐像素完全相同。人物区域结果另见 avatar-frame-check.json，使用旧人物作对照。
- 本机实测约 29.87 fps（采样上限 30）；渲染 JS 提交均值 3.97 ms、P95 6.30 ms；暂停 600 ms 内渲染次数 0。首次本地就绪约 1.85 秒。
- 性能是一次本地浏览器测量，JS 提交时间不是独立 GPU 耗时，本地就绪时间不是公网弱网加载保证。
- 模型身份、名字、配色、段落、房间及关联在保存刷新与 JSON 往返后完全一致；旧角色网站和个人 IP 网站都在独立子路径实际打开。
